# Campagne

Qui vive una cartella per ogni campagna. Nel repository c'è solo `esempio/`
(Velmora), una campagna originale che serve da modello e per i test.

Le campagne basate su giochi di ruolo commerciali non sono incluse e non lo
saranno: regole, ambientazioni e testi dei manuali appartengono ai rispettivi
editori. Per giocare con un sistema esistente serve una copia legittima del
manuale. Si crea una campagna vuota e la si prepara dal proprio PDF (vedi il
README principale): il risultato resta sul proprio computer.

Le campagne che create qui sono escluse da git, tranne `esempio/`.
